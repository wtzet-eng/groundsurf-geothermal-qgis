# GroundSurf Studio Connector 0.5.0 — development preview

## Quick start
1. In QGIS Plugin Manager, disable the separate GroundSurf Connect plugin. Keep its files and settings. Install the Connector ZIP, which upgrades Studio by GroundSurf using the same `groundsurf_geothermal` ID. Use a test profile first.
2. Open GroundSurf Studio Connector. Discover is the default tab; Model & Visualise is the established modelling workspace. Zoom to a small area or select a polygon.
3. Type “Find boreholes with geological profiles” and choose Find data. Approve the source query. In a small Berlin-area selection, regional WFS evidence is preferred. Elsewhere in Germany the BGR national location-only service remains available. Other source portals are recommendations, not verified automatic downloads.
4. Choose Add boreholes to map, View original borehole profile (where offered), or Open boreholes in Studio. The profile action opens a validated official image link in the browser. No automatic extraction or image embedding. Records with links do not imply every link was checked or that structured intervals exist.
5. For regional profiles choose the updated Studio 0.11 Preview 4 portable HTML. Connector saves transfers in a unique folder in Documents/GroundSurf Transfers and remembers explicitly selected HTML by hash. The browser requires the user to select Import transfer folder or Import borehole locations. Existing older Studio editions do not support Berlin records.
6. AI is optional. Open AI setup to detect local Ollama models. Approve software/model installation separately. More tools > Check my setup reports whether executables are on PATH, not their compatibility. No cloud fallback. Existing terrain acquisition remains unchanged; broader workflows and combined evidence scene are future work.

## Evidence source and scientific limitations
Berlin official WFS: https://gdi.berlin.de/services/wfs/bohrdaten (bohrdaten:bohrpunkte), native query EPSG:25833, output CRS84 longitude/latitude, bounded to 500 records, exact selected-area spatial filter in QGIS. Dataset metadata: https://daten.berlin.de/datensaetze/geologische-bohrdaten-wfs-e246e572 (dl-de-zero-2.0). Source name, query, retrieval time, profile URL, reported depth and collar height retained. Vertical datum not verified; no measured/terrain-derived elevations inferred, no synthetic layers. One original JPEG was retrieved successfully; the other profile links were not individually downloaded. No image redistribution in the ZIP. National BGR remains location/header only. No additional countries activated. The packaged demo contains 17 real Berlin regional records with original links, not interval logs.

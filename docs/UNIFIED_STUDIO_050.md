# Unified Studio by GroundSurf 0.5.0 (local development)

Based on public Studio by GroundSurf 0.4.14 (7385847), embedding Connect 0.2.6 (594624d) as an internal module. No second plugin instance or second discovery dock. The original groundsurf_geothermal identifier, model storage and ParaView tools remain. Discover is the default workspace, Model & visualise remains one click away. Optional detach is an explicit modelling command. QGIS layers are shared, but published borehole location-only evidence is not automatically promoted to a geological log. AI tool coverage is unchanged: discovery and reviewed terrain workflows, not general autonomous modelling. Existing standalone Studio is not bundled or relicensed.

Install the ZIP only in a test profile or disable the separate Connect plugin first. The provider registration guard preserves modelling if the old provider is already loaded; disable old Connect and reload Studio by GroundSurf to activate discovery. The combined code uses GPL-3.0-or-later (legacy GPL-2.0-or-later grants that option); preserve the original licence notice. Do not publish this branch without reviewing the private Connect source for public distribution. No GitHub push or active plugin file replacement.

Verification: 20 legacy modelling tests and 40 Connect tests under embedded namespace passed. Isolated QGIS functional assertions passed (one dock, discovery, existing modelling project, nine synthetic contacts retained across tabs, inline model shortcut, explicit detach/restore, duplicate provider protection and provider unload). The known shutdown abort remains after successful assertions. Use a disposable XDG_CONFIG_HOME for future GUI tests: the prior isolated profile did not isolate the legacy global last-project setting; the QA reference was cleared, original path not captured.
